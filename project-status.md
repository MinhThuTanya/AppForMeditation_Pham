# Состояние проекта

## Состояние технического задания

ТЗ повторно проверено. Исключено требование о подключении фитнес-браслета (F.10) как нереализуемое на Python в рамках семестра. Упрощено требование записи сна (F.06) — автоматический анализ аудио заменён на ручной ввод тегов. Уточнено требование Аватара (F.08) — 2D вместо 3D.

После работы над дизайном (рабочее название Akii) добавлены требования F.11 «Вести дневник дня», F.12 «Выбрать язык интерфейса», F.13 «Оформить подписку Akii Plus», F.14 «Войти в аккаунт (необязательно)», а также версия для iOS.

## Текущее состояние проекта

- Подготовлена проектная документация (ЛР №1–4), актуализированы ТЗ и UML-диаграммы
- Приложение запускается на компьютере (PyCharm, Python 3.12, Kivy 2.3.1, KivyMD 2.0)
- Реализованы все экраны и основная логика (см. `tasks.md`)
- База данных: 9 таблиц SQLite
- Сервер Akii Server для необязательного аккаунта (FastAPI)
- Модульные тесты проходят
- APK и версия для iOS пока не собраны
