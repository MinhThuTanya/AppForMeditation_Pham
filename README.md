# Akii — приложение для медитации и отслеживания состояния

Мобильное приложение на Python (Kivy + KivyMD 2.0) для Android и iOS.
Курсовая работа, КубГУ. Структура проекта соответствует подразделу 3.2 курсовой.

## Что где лежит

| Папка / файл | Что внутри |
|---|---|
| `main.py` | Точка входа: класс приложения, ScreenManager, нижнее меню |
| `screens/` | Экраны: заставка, вход, главный, медитации и плеер, дневник дня, аватар, SOS, статистика, оценка стресса, дневник настроения, запись сна, Akii Plus, настройки |
| `logic/` | Логика без интерфейса: `database.py`, `stress.py`, `avatar.py`, `analytics.py`, `audio_player.py`, `journal.py`, `billing.py`, `i18n.py`, `account.py` |
| `locales/` | Тексты интерфейса `ru.json` и `en.json` (собираются из `tools/locales_src.py`) |
| `assets/` | `library.json` (каталог), `audio/` (MP3), `images/avatar/` (5 спрайтов), `icons/`, `fonts/` |
| `data/` | Здесь при первом запуске появится база `meditation.db` |
| `server/` | Сервер Akii Server на FastAPI: аккаунты и синхронизация |
| `tests/` | Модульные проверки логики и сервера |
| `tools/` | Скрипты: генерация спрайтов аватара и иконки, сборка языковых файлов |
| `buildozer.spec` | Настройки сборки APK |

## Запуск на компьютере (PyCharm)

1. Откройте папку проекта в PyCharm: **File → Open → App for meditation**.
2. Создайте виртуальное окружение: **Settings → Project → Python Interpreter → Add Interpreter → Virtualenv** (Python 3.11–3.13).
3. В терминале PyCharm выполните:
   ```
   pip install -r requirements.txt
   ```
4. Запустите `main.py` (правой кнопкой → **Run 'main'**). Откроется окно размером с телефон.

Если не слышно звука MP3, установите дополнительно `pip install ffpyplayer`.

## Проверки

```
python -m unittest discover tests
```
Проверяются случаи T1, T2, T6, T7, T13 из курсовой, подписка в тестовом режиме, кнопки входа по региону, достижения.
Проверки сервера запускаются, если установлены библиотеки из `server/requirements.txt`.

## Сервер (нужен только для аккаунта)

```
pip install -r server/requirements.txt
uvicorn server.main:app --reload
```
Документация API: http://127.0.0.1:8000/docs. Без настроек почты ссылка для подтверждения регистрации
печатается в консоли сервера — откройте её в браузере, потом войдите в приложении.
Для работы с PostgreSQL задайте переменную `AKII_DATABASE_URL=postgresql+psycopg://...`.

Без сервера приложение полностью работает: на экране входа нажмите «Продолжить без аккаунта».

## Сборка для телефона

- **Android** (в WSL / Ubuntu): `pip install buildozer`, затем `buildozer android debug` — APK появится в папке `bin/`.
- **iOS** (только на Mac с Xcode): `pip install kivy-ios`, `toolchain build python3 kivy`,
  `toolchain pip install kivymd plyer`, `toolchain create Akii <путь к проекту>` — появится папка `akii-ios/`.

## Установка на iPhone без Mac

1. **Собрать .ipa.** На GitHub откройте вкладку **Actions** → «Сборка для iOS» → **Run workflow**. Сборка идёт на облачном Mac 30–60 минут (повторные быстрее). Когда она закончится, внизу страницы запуска в разделе **Artifacts** скачайте `Akii-unsigned-ipa` и распакуйте zip — внутри `Akii-unsigned.ipa`.
2. **Подготовить компьютер.** Установите iTunes с сайта Apple (не из Microsoft Store) и программу Sideloadly (sideloadly.io).
3. **Установить.** Подключите iPhone кабелем, перетащите `Akii-unsigned.ipa` в окно Sideloadly, введите свой Apple ID и нажмите **Start**.
4. **Разрешить запуск на iPhone.** Настройки → Конфиденциальность и безопасность → **Режим разработчика** (включить, телефон перезагрузится). Затем Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».

С бесплатным Apple ID приложение работает 7 дней — потом установите его заново тем же способом (записи сохраняются, если не удалять приложение). Одновременно можно держать до 3 таких приложений.

## Что ещё предстоит (по плану разработки)

- **Этап 9.3 — оплата в магазинах.** Сейчас на компьютере подписка Akii Plus включается в тестовом режиме без оплаты. RuStore Pay SDK (Android, через Pyjnius) и StoreKit (iOS, через Pyobjus) подключаются при сборке под телефон.
- **Этап 9.4 — вход через сервисы.** Вход через VK ID, Google и Apple заработает после регистрации приложения в их кабинетах: нужно вписать client_id в `logic/account.py` и в переменные сервера. Вход по почте работает уже сейчас.
- **Хранение токена на телефоне.** Нужно сохранять токен в Android Keystore / iOS Keychain. Сейчас на компьютере он хранится только в памяти.
- **Напоминания.** Сейчас они приходят, пока приложение открыто. Фоновые уведомления настраиваются в сборке под телефон.
- **Звуки и голос гида.** Нужно добавить файл `assets/audio/forest.mp3` (звук «Лес») и записи голоса гида. Пока вместо голоса на экране показываются текстовые подсказки.
